rs-plugkit scan_deps.rs invariants, drained from rs-plugkit/AGENTS.md to keep it under its 30KB ceiling. find_suspicious_escapes requires an identifier shape, not printable ASCII (escaped CSS punctuation would fail the scan); count_hex_obfuscator_idents covers the escape-free _0x variant; a size ratio alone only warns, never fails. walk_package signs a package by max mtime_ms plus summed size (a directory mtime alone misses in-place edits) and walks node_modules per package with list_dir; IndexConfig::is_force_included is a substring match and would force-include every descendant of a matched path, not just the named one. scan_one_file: a file over MAX_SCAN_BYTES warns without a content scan; host_read returning None with a stat size > 0 is a blocked read (antivirus), which fails the scan outright, while a stat size of 0 is legitimately an empty file.
