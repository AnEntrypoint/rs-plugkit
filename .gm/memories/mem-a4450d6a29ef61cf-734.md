plugkit/cache-rs-contract: cache::get returns Result<Option<Entry>>: Err means the store could not answer and must never be treated as a miss that overwrites state; expiry is filtered in the SELECT so an expired row is unreachable before any sweep. ensure_schema runs on every public op (no process-global init flag) because one plugin instance serves several projects' db files. The LRU touch in get and enforce_budget in put are best-effort. CacheError::Store keeps the libsql message verbatim so shared_db::is_malformed_by_sqlite_error_code can classify it. The libsql plugin returns integer columns as a JSON number, float or string depending on driver path; cache::row_i64 and code_index::chunk_rows_by_path read all three forms.
