rs-plugkit plugin_abi.rs invariants, drained from rs-plugkit/AGENTS.md to keep it under its 30KB ceiling. call() merges the {abi, plugin, verb, body} envelope over the body's own top-level fields, with envelope keys applied last (winning on conflict); pre-envelope libsql/bert plugin calls read top-level fields directly, so sending only the nested envelope to one of those older plugins breaks every call. parse_response: a null or empty-object reply (the host's empty pointer pair) is classified PluginNotFound; an ok:true reply with no data field returns the whole response object minus the ok/abi keys, which is what keeps legacy rows/embedding-shaped results working. AbiErrorKind wire strings (plugin-not-found, verb-not-supported, plugin-error, timeout) are frozen wire contract strings; without an explicit kind field in the response, classify_failure falls back to sniffing the literal unknown verb / verb not supported text that verbs.rs emits in its own error messages.
